🛡️ About Security Digest

📌 Project Overview

Security Digest is an automated cybersecurity threat intelligence monitoring system designed to collect, analyse, and deliver security information from multiple online sources. The system reduces the difficulty of manually monitoring cybersecurity news by automatically gathering security reports, analysing their risk level, generating concise summaries, and presenting useful intelligence through a web-based dashboard.

The platform combines automated data collection, AI-assisted summarisation, threat severity classification, CVE detection, protection recommendations, database management, dashboard visualisation, and email notification features to provide users with a simple Security Operations Centre (SOC)-style monitoring environment.

⚙️ System Workflow

  1. Threat Data Collection: The system automatically collects cybersecurity articles from configured RSS security feeds.
  2. Article Filtering: Collected articles are filtered according to the configured time period, and duplicate articles are removed before further processing.
  3. Article Extraction: The system attempts to extract the article content from the original webpage. If webpage extraction is unavailable, the RSS description is used as a fallback.
  4. AI Summarisation: Available article content is converted into a concise security summary using the Groq API to improve readability and reduce the time required to review security reports.
  5. Threat Classification and Scoring: Articles are analysed using a rule-based scoring engine. The resulting threat score and classification rules are used to assign Critical, High, Medium, or Low severity levels.
  6. CVE Detection: The system searches the available article information for valid CVE identifiers and records detected CVEs while removing duplicate identifiers.
  7. Protection Recommendation: Security recommendations are generated according to the article category and severity to provide practical guidance for responding to identified threats.
  8. Database Storage: Processed security intelligence, including article information, summaries, severity, scores, CVEs, recommendations, and alert status, is stored using SQLite.
  9. Notification Delivery: The system sends daily security digest emails and Critical security alerts according to user notification preferences.

💻 Technology Stack

  • Programming Language: Python – Core backend processing, automation, threat analysis, and email functionality.
  • Web Framework: Flask – Provides dashboard routing, authentication, article views, and web application functionality.
  • Database: SQLite – Stores users, articles, threat scores, summaries, CVE information, recommendations, and notification status.
  • AI Integration: Groq API – Generates concise cybersecurity article summaries.
  • Frontend: HTML5, Bootstrap, and JavaScript – Creates the responsive user interface and dashboard functionality.
  • Data Visualisation: Chart.js – Displays security statistics and threat trends through interactive charts.
  • RSS Processing: Feedparser and HTTP requests – Collect and process cybersecurity RSS feeds.
  • Email Automation: SMTP and Python email modules – Deliver daily security digest emails and Critical security alerts.

📧 Email Notification System

Security Digest provides two main types of email notifications.

Daily Security Digest: Provides users with a summary of the cybersecurity articles collected and processed by the system.

Critical Security Alerts: Provides notifications when an article is classified as Critical according to the implemented severity rules.

Alert delivery is controlled by user preferences, including notification type and minimum severity threshold. Critical articles are stored in the database with an alert status. After an alert is successfully sent, the delivery status is updated to help prevent the same alert from being sent again.

The alert checking process reads Critical articles from the database rather than repeatedly collecting RSS feeds. This separates the article collection process from the notification process.

⏰ Automated Scheduling

The system uses an automated scheduler to run the main background tasks without requiring each process to be started manually.

  • Article Collection: Periodically collects and processes new cybersecurity articles.
  • Critical Alert Check: Periodically checks the database for unsent Critical security alerts.
  • Daily Digest: Sends the daily security digest according to the configured schedule.

The scheduling intervals can be temporarily shortened during system demonstrations and testing to allow automated functions to be verified without waiting for the normal production schedule.

🎯 Project Purpose

The purpose of Security Digest is to provide an automated and user-friendly threat intelligence platform that helps users monitor cybersecurity risks efficiently. The system demonstrates how automation, artificial intelligence, databases, web technologies, threat classification, and email services can be combined to support cybersecurity monitoring and threat intelligence activities.
